# The storefront (home, categories, product families) is open to every crawler.
#
# Disallowed: areas behind a sign-in, per-visitor pages, and the API. Search is
# out too: every query string is a new URL, so a crawler following search links
# never runs out of pages and burns the monthly request quota doing it.
#
# Each locale is spelled out rather than written `/*/rep`: in robots.txt `*`
# also matches slashes, so the wildcard would hide any product family whose
# slug starts with "rep", "cart", "quote" and so on (/fa/f/repair-kits).
#
# Public pages that must stay out of results (/track, /pay, /invoice) are NOT
# listed on purpose: they carry a `noindex` tag, and a crawler barred here
# never fetches the page to see it, so it could still list the bare URL.
User-agent: *
Disallow: /api/
Disallow: /en/admin
Disallow: /fa/admin
Disallow: /en/rep
Disallow: /fa/rep
Disallow: /en/account
Disallow: /fa/account
Disallow: /en/cart
Disallow: /fa/cart
Disallow: /en/quick-order
Disallow: /fa/quick-order
Disallow: /en/quote
Disallow: /fa/quote
Disallow: /en/search
Disallow: /fa/search
# Rep referral links: each is a redirect that costs a database read, and no
# page links to one, so only a crawler guessing codes would fetch them.
Disallow: /en/r/
Disallow: /fa/r/
# Filtered family views, for the same reason as search: each filter link opens
# a URL carrying more filter links, so the combinations never run out, and the
# family route reads its query string, so every one is rendered from the
# database. In October 2026 ~90% of family renders were these, nearly all from
# crawlers — the likely main cause of the database going over its monthly
# transfer quota. The bare family page (no `?`) stays open.
Disallow: /en/f/*?
Disallow: /fa/f/*?
# Category list views past the first page (`?page=N`): the list route reads
# its query string too, so every page is rendered from the database, and the
# pager links from each to the next — about 340 pages per language, the deepest
# sorting ~12,900 rows per request (review R-3). The bare list page stays open.
Disallow: /en/l/*?
Disallow: /fa/l/*?

# Baidu: no buyers in this market, and ~29k requests a day in October 2026 —
# ~13k on one family page and ~12k from its page-rendering crawler on the cart
# API. The firewall denies it too; this is for the crawler that reads
# robots.txt before it is refused.
User-agent: Baiduspider
Disallow: /

# OpenAI's training crawler: ~80k requests a day in October 2026, most of the
# free plan's monthly quota on its own. It only gathers training text, so
# barring it costs no visibility — ChatGPT search (OAI-SearchBot) and
# ChatGPT fetching a page on a user's behalf (ChatGPT-User) are separate
# agents, still allowed by the group above. A bot obeys only its most specific
# group, so this one is out of the whole site.
User-agent: GPTBot
Disallow: /
